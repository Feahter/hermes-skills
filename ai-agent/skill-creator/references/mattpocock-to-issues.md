# Plan → Issues — from mattpocock/to-issues

> Break a plan, spec, or PRD into independently-grabbable issues on the project issue tracker.

## When to Use
- User wants to convert a plan into issues
- Create implementation tickets from a spec
- Break down work into vertical slices

## Key Principle: Vertical Slices

Each issue = one end-to-end feature increment, not a layer.
❌ Bad: "Write the database schema" / "Write the API" / "Write the frontend"
✅ Good: "User can sign up" / "User can reset password"

## Output
Tickets on the project issue tracker with:
- Clear description
- Acceptance criteria
- Priority label
- Assignee (or "up for grabs")

## Key Triggers
- "break this into issues"
- "create tickets"
- "plan this out"
- "vertical slices"
