# Context → PRD — from mattpocock/to-prd

> Turn the current conversation context into a PRD and publish it to the project issue tracker.

## When to Use
- User wants to formalize current discussion into a PRD
- Capture a decision that was made
- Create a formal spec from conversational planning

## Output
PRD document published to the project issue tracker with:
- Problem statement
- Goals / Non-goals
- User stories / use cases
- Technical approach
- Acceptance criteria
- Open questions

## Key Triggers
- "write this up as a PRD"
- "formalize this"
- "create a spec from this"
- "document this decision"
