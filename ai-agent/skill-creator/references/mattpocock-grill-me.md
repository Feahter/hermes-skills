# Design Stress-Test — from mattpocock/grill-me

> Interview the user relentlessly about a plan or design until reaching shared understanding, resolving each branch of the decision tree.

## When to Use
- User wants to stress-test a plan
- User wants to be "grilled" on their design
- Pre-implementation validation

## Method
- One question per message
- Prefer multiple choice questions
- Resolve each branch of the decision tree before moving on
- Continue until no new uncertainty remains

## Key Triggers
- "grill me"
- "stress test this"
- "challenge my design"
- "question this plan"
