# 横纵分析法 (Horizontal-Vertical Analysis)

> 作者：数字生命卡兹克 | 来源：https://github.com/KKKKhazix/khazix-skills

一套深度研究框架，核心是**双轴分析**：纵轴追踪从诞生到当下的完整生命历程，横轴在当下截面上与竞品系统性对比，最后交叉产出独到洞察。

## 触发词

横纵分析、研究一下、帮我分析、深度研究、做个研究、调研一下、竞品分析、帮我看看这个东西怎么样、这个产品/公司/概念是怎么回事、帮我摸清楚、搞懂、做个deep research

## 不适用场景

- 简单名词解释（用普通对话）
- 公众号写作（用 `khazix-writer`）
- 纯标题摘要生成

---

## 五步执行流程

### Step 0: 前置准备

1. **明确研究对象**：
   - 研究对象（产品名/公司名/概念名/人名）
   - 类型：产品、公司、概念、人物
   - 研究动机（可选）
   - 特别关注点（可选）

### Step 1: 联网信息收集（关键！）

**并行搜索策略**：使用子Agent分工
| 子Agent | 负责领域 |
|---------|---------|
| 子Agent 1 — 纵向 | 起源、创始人、发展历程、关键事件、版本迭代、融资、战略转向 |
| 子Agent 2 — 横向 | 竞品识别、特点、用户口碑、行业评测、市场份额 |
| 子Agent 3（可选） | 深度背景、行业环境、用户社区 |

**信息来源优先级**：
| 信息类型 | 一手来源 |
|---------|---------|
| 产品/技术决策 | 官方博客、GitHub Release Notes、创始人推文 |
| 融资/商业 | 公司公告、SEC/工商文件 |
| 用户口碑 | GitHub Issues、Reddit、Twitter/X、知乎 |
| 行业分析 | 权威媒体原创报道 |
| 学术/技术 | arXiv论文、Google Scholar |

**学术类必查arXiv**：
```bash
curl -s "https://export.arxiv.org/api/query?search_query=all:关键词1+AND+all:关键词2&max_results=10"
```

**自检**：纵向能讲完整故事吗？横向竞品列表完整吗？关键事实有可靠来源吗？

### Step 2: 纵向分析（6,000-15,000字）

**内容要求**：
- **起源追溯**：诞生背景、技术/理念/需求来源、创始团队背景、当时行业环境、关键灵感
- **诞生节点**：首次发布/成立时间、最初形态和定位
- **演进历程**：按时间顺序梳理所有关键节点（版本更新、融资、团队变动、战略转向、技术架构、用户里程碑、重大合作/收购、危机）
- **决策逻辑**：还原每个关键节点的决策原因和约束条件，识别"锁定"后期发展的早期决策
- **阶段划分**：自然分为萌芽期、快速增长期、转型期等，每个阶段有核心特征和核心矛盾

**核心原则**：把故事讲完整讲透，不要为了压缩跳过重要细节。

### Step 3: 横向分析（3,000-10,000字）

**竞品场景判断**：
| 场景 | 处理方式 | 篇幅 |
|-----|---------|-----|
| A：无直接竞品 | 分析为何无竞品、未来竞争者来源、间接替代方案 | ~3,000字 |
| B：少量竞品（1-2个） | 逐一深入对比 | 每个1500字+ |
| C：竞品充分（3个+） | 选3-5个代表性深入，其余简要提及 | 每个1500字+ |

**对比维度**：
- 核心差异（技术路线/方法论、产品形态、商业模式、目标用户、核心优劣势、定价）
- **用户视角**：真实口碑、社区评价、使用方式与官方定位的偏差
- 生态位分析：占据什么位置？填补空白还是正面竞争？格局是什么？
- 趋势判断：机会和风险

### Step 4: 横纵交汇洞察（1,500-3,000字）

**核心问题**：
1. 历史如何塑造了当下的竞争位置？
2. 竞品的纵向对比——起源和演变路径的不同如何导致今天的特点？
3. 优势的**历史根源**
4. 劣势的**历史根源**（"好决策"是否变成包袱？）
5. **未来三个剧本**：最可能的、最危险的、最乐观的

**核心原则**：给出综合性的新判断，不是前面内容的缩写版。

### Step 5: 生成PDF报告

如需生成PDF：
```bash
pip install weasyprint markdown 2>/dev/null
python [skill目录]/scripts/md_to_pdf.py input.md output.pdf \
  --title "研究对象名称" --author "横纵分析法"
```

**Markdown写作注意事项**：
- 第一行 `# 标题` 作为封面标题
- 紧接标题后用 `> 研究时间：... | 所属领域：... | 研究对象类型：...` 写元信息
- 用 `##` 作为主要章节标题，`###` 和 `####` 作为子章节

## 写作风格

### 应借鉴的元素

| 元素 | 说明 |
|-----|-----|
| **节奏感** | 句子时长时短，段落跳跃自然；一句话自成一段制造重量感 |
| **叙事驱动** | 有故事弧线、起承转合，不是"2023年1月发布A，2023年3月发布B"流水账 |
| **知识顺手掏** | 在讲述中自然带出背景知识，不刻意"科普" |
| **敢下判断** | 观点有事实支撑，用「我觉得」「我的判断是」承认主观性 |
| **层层剥开** | 现象→表面解释→更深的追问→核心洞察 |
| **文化升维** | 连接到更大的文化/哲学/历史参照物 |
| **回环呼应** | 开头埋的钩子在结尾callback |

### 需要克制的元素

- 过强的口语化（可以有偶尔点缀，但密度要低）
- 去小标题化（1-3万字需要清晰结构导航）
- 冒号和破折号可以正常使用
- 不要公众号三连/星标尾部

---

## 绝对禁区（任何文体都避免）

| 类型 | 举例 |
|-----|-----|
| 套话 | 首先...其次...最后、综上所述、值得注意的是、不难发现 |
| 空洞形容词 | 赋能、抓手、打造闭环 |
| 教科书开头 | 在当今AI快速发展的时代、随着技术的不断进步 |
| 高频踩雷词 | 说白了、意味着什么？、这意味着、本质上、换句话说、不可否认 |
| 空泛工具名 | AI工具、某个模型 → 说具体名字 |
| 编造场景 | 搜不到的信息标注「该信息暂缺」，绝不编造 |

---

## 不同研究对象类型的适配

| 类型 | 纵轴重点 | 横轴重点 |
|-----|---------|---------|
| **产品** | 版本迭代、技术路线、用户增长、关键产品决策 | 功能对比、性能、用户体验、定价 |
| **公司** | 创始团队、融资、战略转向、组织变革、人事变动 | 商业模式、市场份额、营收、组织架构 |
| **概念** | 起源（谁提出、基于什么理论）、流行过程、争论演变 | 与相近概念的区别、适用场景、不同阵营论证 |
| **人物** | 个人经历、职业轨迹、关键决策、成长曲线、公开言论变化 | 与同领域人物对比（做事方式、风格、成就、影响力、路线选择）|

| 部分 | 字数范围 |
|-----|---------|
| 纵向分析 | 6,000-15,000字 |
| 横向分析 | 3,000-10,000字 |
| 横纵交汇 | 1,500-3,000字 |
| **全文总计** | **10,000-30,000字** |

## 报告结构模板

```
# 研究对象名称
> 研究时间：... | 所属领域：... | 研究对象类型：...

## 一、一句话定义
   [用一句话说清楚这个东西是什么]

## 二、纵向分析：从诞生到当下
   [完整的纵向叙事，6000-15000字]

## 三、横向分析：竞争图谱
   [横向对比分析，3000-10000字]

## 四、横纵交汇洞察
   [交叉分析和未来推演，1500-3000字]

## 五、信息来源
   [所有引用的来源列表]
```

## 质检清单（交付前自检）

- [ ] 纵轴是叙事故事体？有因果逻辑和时代脉络？不是年表流水账？
- [ ] 创始人/发起者背景和动机有足够深度？
- [ ] 每个关键节点都展开了？
- [ ] 决策逻辑有还原？有"为什么这么选"？
- [ ] 横轴竞品场景判断正确？竞品分析够深？
- [ ] 用户口碑引用了真实用户声音？不只是官方宣传？
- [ ] 横纵交汇产出新判断？不是前面内容的缩写版？
- [ ] 未来三个剧本都有逻辑支撑？
- [ ] 写作风格有节奏感？有可读性？
- [ ] 没有触犯绝对禁区？
- [ ] 所有关键事实标注信息来源？
- [ ] 搜不到的信息诚实标注「暂缺」？
- [ ] 总字数在10,000-30,000字范围内？
