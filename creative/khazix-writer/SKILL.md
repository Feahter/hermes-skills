# 卡兹克公众号长文写作 Skill

> 作者：数字生命卡兹克 | 来源：https://github.com/KKKKhazix/khazix-skills
> 使命：激发大家对AI的好奇

## 核心定位

**写作风格定位**：「有见识的普通人在认真聊一件打动他的事。」

**使用场景**：公众号长文写作、续写、扩写、按素材出稿

**禁用场景**：短内容（小红书/朋友圈）、纯标题生成

---

## 第一步：理解素材与选题判断

### HKR 选题质检

| 维度 | 要求 |
|------|------|
| **H** (Happy) | 有趣有悬念，标题让人想点开 |
| **K** (Knowledge) | 有信息量，看完能学到东西 |
| **R** (Resonance) | 戳中情绪，让人"对对对" |

- **S级选题**：三项兼备
- **及格选题**：至少占两项
- **素材不足时**：主动追问用户要点、个人经历、兴奋/吐槽点

---

## 第二步：AI角色边界

### ✅ AI擅长做的

- **找证据和佐证**：历史/学术/文化素材支撑观点
- **找类比和比喻**：解释抽象概念时提供候选
- **按确定角度扩写**：核心观点已定，AI填充论述
- **补充学科背景**：格式塔心理学、因果语言模型等
- **梳理逻辑结构**：调整段落顺序

### ❌ 必须人做的

- **第一手观察和真实经历**：亲自去买9.9的DeepSeek、凌晨三点去网吧
- **核心创意角度**：从"淘宝卖DeepSeek"联想到"北京折叠"
- **情绪的真实表达**："我当时就愣住了"（体感）vs "我当时很震撼"（知识性）
- **数据到人物的同理心**：从"1000个已付款"想象具体的人

### 理想协作流程

```
人：素材 + 核心观点 + 个人经历 + 情绪节点
    ↓
AI：补充知识 + 证据类比 + 结构建议 + 按角度扩写
    ↓
人：二次改写（加入声音、打破节奏、补充细节）
    ↓
AI：四层自检 → 输出修改建议
    ↓
人：终审定稿
```

## 第三步：写作

### 五种文章原型

| 原型 | 核心 | 写法重心 |
|------|------|----------|
| **调查实验型** | "我替你去做了" | 过程叙事 + 层层递进发现 |
| **产品体验型** | "跟我一起玩" | 场景演示 + 真实感受 |
| **现象解读型** | "你注意到了吗？背后是什么？" | 观察→好奇→研究→哲学升维 |
| **工具分享型** | "我发现了一个好东西" | 个人故事铺垫→工具展示→效果惊艳 |
| **方法论分享型** | "压箱底的东西掏给你" | 每节有可执行行动 + 坦诚说明学习成本 |

### 风格内核

#### 节奏感
- 像跟朋友聊天，不像写报告
- 句子时长时短，大量用逗号制造口语停顿
- 一句话自成一段制造重点
- **扣主线句**：偏出去的内容用一句话拉回来

#### 论述中的故意打破
- 重复强调："就是...就是...就是单纯的，想看看"
- 中途叹息打断："我当时就..."
- 省略主语："想看看"而非"想要了解一下"
- 刻意模糊："我就不说是谁了"

#### 知识输出方式
> "聊着聊着顺手掏出来的"，不是"下面我来科普一下"

#### 其他核心技巧

- **私人视角**："我也面临这个问题"而非"这给我们的启示是"
- **判断力**：敢下判断，"我被打动了"
- **对立面理解**：先承认对方处境合理，再切入不同视角
- **情绪标点**：``...``（拖长/震惊）、`？？？`（极度惊讶）、`==`（无语吐槽）
- **亲自下场**：读者感觉到"这个人真的做了"
- **人物画像法**：数据→代入→多维堆砌→情感锚定→细节具象化
- **文化升维**：聊完具体事，连接到更大文化/哲学/历史参照
- **句式断裂**："黑暗森林。""大时代啊，朋友们。"
- **回环呼应**：前面埋的钩子后面callback回来
- **谦逊铺垫**："我也不知道行不行""不成熟的经验"
- **读者直呼**："屏幕前的你""你相信我"
- **层层剥开**：现象→表面解释→更深的追问→核心洞察
- **英雄之旅**：普通人被召唤→冒险→考验→宝物→带着变化回归
- **反向论证**：先满足期待再打破它

## 绝对禁区

### 套话禁用
- `首先...其次...最后`
- `综上所述`
- `值得注意的是`
- `不难发现`
- `让我们来看看`
- `接下来让我们`

### 标点禁令

| 禁用 | 替代 |
|------|------|
| 冒号 `：` | 逗号 `,` |
| 破折号 `——` | 逗号或句号 |
| 双引号 `" "` `" "` | `「」` 或不加引号 |

### 高频踩雷词

```
"说白了" ← AI最爱用
"意味着什么？" ← AI标志性句式
"这意味着" ← 换口语表达
"本质上" ← 太学术
"换句话说" ← 太书面
"不可否认" ← 套话
```

### 其他禁区

- **假设性例子**："比如有一次..."编造场景是大忌
- **空泛工具名**："AI工具""某个模型"→ 要说具体名字
- **教科书开头**："在当今AI时代"→ 从具体当下事件切入

## 推荐口语化词组

### 转场过渡
> 坦率的讲、说真的、我是真的觉得、反正我觉得、怎么说呢、其实吧、你想想看、我跟你说、回到xxx这块、顺着上面的再聊聊

### 表达判断
> 我有时候觉得、我一直觉得、这话听着有点刺耳但、不是说xxx不行而是说、我自己的感受是

### 承认自嘲
> 说实话我也不确定、我自己也还在摸索、可能有些想法还不成熟、愚钝如我、这事儿我也踩过坑

### 情绪表达
> 这种感觉太爽了、我当时就愣住了、太离谱了、太特么赤鸡了、给我一下子整不会了、你敢信？？？

### 拉近距离
> 很多朋友可能不知道、可能有小伙伴纳闷、你如果关注这个领域的话

### 口头禅
> 这玩意、不是哥们、我寻思了一下、有个屁的xxx、比较骚的事

## 开头必杀技

1. **叙事启动**："故事是这样的。" / "事情是这样的。"
2. **荒诞事实**：直接抛出让人`？？？`的事实
3. **热点破题**："最近这两天，被一个三宫格AI图片给刷屏了。"
4. **好奇心驱动**："这两天在网上刷到了一张图，很有意思。"

---

## 逐一展示法（升番逻辑）

- 不要一次性罗列结论，逐个展示带吐槽
- 遵循**升番逻辑**：基础→进阶→出乎意料的骚操作
- 排列顺序决定情绪曲线，**最弱的放前面，最炸的留最后**

---

## 文章结构模板

```
【开头】感性切入，从具体事件/场景开始
    ↓
【背景铺垫】聊天式科普，非专业读者也能懂
    ↓
【核心内容】
  - 明确观点
  - 具体场景/人物/对话支撑
  - 私人视角连接
  - 扣主线句拉回来
    ↓
【升华】连接更大文化/哲学/历史参照
    ↓
【收尾】选最合适的一种：
  - 引用收尾
  - 哲思余韵
  - 行动呼吁
  - 信念宣言
  - 回环呼应
    ↓
【固定尾部】
以上，既然看到这里了，如果觉得不错，随手点个赞、在看、转发三连吧...
> / 作者：卡兹克
```

### 字数与格式

- **字数**：4000-8000字
- **段落**：要短，一句话就是一段
- **小标题**：绝大多数情况不加，从头到尾一口气顺下来
- **转场**：用口语化句子衔接

## 第四步：四层自检体系

### L1 硬性规则检查

**L1-1 禁用词扫描**：`说白了`、`意味着什么`、`本质上`、`换句话说`、`不可否认`、`综上所述`等

**L1-2 禁用标点扫描**：冒号、破折号、双引号

**L1-3 结构性套话扫描**：让我们来看看、随着...发展、连续bullet point

**L1-4 工具名检查**：确保所有工具都有具体名称

> **通过标准**：四项零命中

### L2 风格一致性检查

**L2-1 开头检查**：是否从具体当下事件切入？是否有"然后呢"冲动？

**L2-2 节奏结构检查**：
- 长短句交替（连续3句以上句式相近=呆板）
- 一句话独立成段出现≥3次
- 偏线段落有扣主线句
- 疑问句制造刹车转向
- 无不必要小标题

**L2-3 口语化检查**：
- 口语词组≥8-10个不同表达
- 论述中的故意打破
- 至少一处自嘲或承认不足
- 情绪标点（``...``、`？？？`、`==`至少一种）

**L2-4 标点禁令二次确认**

> **通过标准**：L2-1全过，L2-2和L2-3至少3/4过，L2-4通过

### L3 内容质量检查

**L3-1 观点支撑**：每个核心观点有具体人/场景/细节/数据

**L3-2 知识输出方式**：以"聊着聊着顺手掏出"而非"我来科普"

**L3-3 文化升维**：至少一处连接到更大参照物，且自然

**L3-4 对立面与同理心**：承认对方立场后再切入自己视角

**L3-5 类型专项检查**：
| 类型 | 检查重点 |
|------|----------|
| 调查实验型 | 亲自下场的叙事感？层层递进发现？ |
| 产品体验型 | 真实使用场景？自然对比？ |
| 现象解读型 | 观察→好奇→研究→升维推进？ |
| 工具分享型 | 个人故事铺垫？效果让人卧槽？ |
| 方法论分享型 | 每节有可执行行动？坦诚学习成本？ |

**L3-6 逐一展示检查**：多产品/案例是否逐一展示带吐槽

> **通过标准**：L3-1和L3-2全过，L3-3至L3-6至少通过相关项

### L4 活人感终审

**核心问题**：读起来是"有见识的普通人在认真聊"还是"AI在输出信息"？

| 维度 | 检查点 |
|------|--------|
| **温度感** | 情绪是体感记忆还是知识性描述？人物有体温感？ |
| **独特性** | 只有卡兹克才会写的角度？ |
| **姿态** | 普通人在聊天？不是导师教学生？ |
| **心流** | 有没有注意力断掉的点？ |

> **通过标准**：整体感觉"像真人写的"

## 关键方法论

1. **选题先过HKR质检**：至少占两项，否则调整方向
2. **人机协作分工明确**：AI做素材和启发，核心创意和情绪必须人来做
3. **五原型判断先行**：写前先判断属于哪种，写法重心随之调整
