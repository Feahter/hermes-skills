# Blade of Logic — from thinking/blade-of-logic

> Propositional reasoning — dissect text logic with symbolic operators.

## Core Concept

### Propositions
Statements that can be definitively true or false. Represented as letters [A, B, C].

### Operators
| Symbol | Meaning |
|--------|---------|
| ¬ | NOT |
| ∀ | For all |
| ∃ | There exists |
| → | If-then (sufficient condition) |
| ∧ | AND |
| ∨ | OR |

### Inference
| Symbol | Meaning |
|--------|---------|
| ⇒ | Derives |
| ⇔ | Equivalent |

## When to Use
- Analyzing argumentation structure
- Identifying logical fallacies
- Building rigorous deductions
- Academic writing

## Method
1. Extract core propositions from text
2. Formalize with operators
3. Build logical chains using inference rules
4. Translate back to natural language
