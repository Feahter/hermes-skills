# Mirror of Perspectives — from thinking/mirror-of-perspectives

> Find the angle that makes the problem trivially simple.

## Core Principle
**For any problem, there exists an observation angle that makes it suddenly simple.**
The key is not harder — it's different.

## When to Use
- Problem-solving stagnation
- Breakthrough thinking needed
- Product design
- Strategic decisions

## Perspective Toolbox

### 1. Scale Shifting
- Zoom out (macroeconomic view)
- Zoom in (microscopic detail)
- Time scale (100-year view, or this moment)

### 2. Cross-Disciplinary Analogy
- Physics concepts applied to business
- Biology perspective on organizations
- Math thinking on relationships

### 3. Extreme Cases
- If resources were unlimited?
- If resources were zero?
- If time were scarce/abundant?

### 4. System Thinking
- Context > elements
- Look for feedback loops
- Find leverage points

### 5. Reverse Thinking
- What if we did the opposite?
- Backward from the goal

### 6. First Principles
- Strip to most basic facts
- What if we could only keep one thing?

### 7. Historical View
- How was this solved before?
- What can ancient wisdom teach?

### 8. Breaking the Frame
- What if rules didn't exist?
- Alien viewpoint

## Method
1. Apply toolbox systematically
2. Find the perspective that maximally simplifies
3. Execute from that angle
