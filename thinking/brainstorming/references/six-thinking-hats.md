# Six Thinking Hats — from thinking/six-thinking-hats

> De Bono's parallel thinking method — six dimensions analyzed in sequence.

## Core Idea
- **Parallel thinking**: everyone wears the same hat at the same time, thinking in the same direction
- **Sequential**: each hat is used separately, not mixed
- **Complete coverage**: six hats = six dimensions, nothing missed

## The Six Hats

| Hat | Focus | Key Question |
|-----|-------|-------------|
| ⚪ White | Facts, information | What do we know? What's missing? |
| ❤️ Red | Emotions, intuition | How do I feel about this? |
| ⚫ Black | Risks, problems | What could go wrong? |
| 💛 Yellow | Benefits, opportunities | What's good about this? |
| 💚 Green | Creativity, alternatives | What else can we try? |
| 🔵 Blue | Process control,总结 | What's the next step? |

## When to Use
- Major decisions
- Team discussions
- Comprehensive problem analysis
- Innovation workshops

## Quick Template (30-min personal)

```
⚪ White (5min) — list all known facts
❤️ Red (3min) — record gut feelings
⚫ Black (7min) — find all risks/problems
💛 Yellow (5min) — find all benefits/opportunities
💚 Green (7min) — propose alternatives
🔵 Blue (3min) — summarize, decide next action
```
