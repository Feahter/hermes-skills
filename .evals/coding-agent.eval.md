# coding-agent.evals

> Skill: coding-agent
> Description: 自主编码执行引擎 — 用于所有写代码/创建/实现/重构/调试/优化/ship 软件的场景
> Last updated: 2026-05-13

---

## POSITIVE — 应该触发

| # | 触发词 | 预期行为 | 边界条件 |
|---|--------|----------|----------|
| P1 | "帮我写一个快速排序" | 触发 coding-agent | 明确要求写代码 |
| P2 | "写段Python代码处理这个JSON" | 触发 coding-agent | 短 query 但意图明确 |
| P3 | "帮我实现这个功能" | 触发 coding-agent | 功能=代码实现 |
| P4 | "代码有个bug，帮我看看" | 触发 coding-agent | 调试是编码任务子集 |
| P5 | "优化一下这段SQL性能" | 触发 coding-agent | 优化也是编码任务 |
| P6 | "搭建一个博客项目" | 触发 coding-agent | 初始化项目 = 编码任务 |
| P7 | "把这个函数重构一下" | 触发 coding-agent | 重构是编码任务 |
| P8 | "写个脚本自动处理这些文件" | 触发 coding-agent | 脚本 = 代码 |

---

## NEGATIVE — 不应触发

| # | 触发词 | 不触发原因 | 正确路由 |
|---|--------|------------|----------|
| N1 | "解释一下快速排序的原理" | 纯解释不需要写代码 | 无需 skill（直接回答） |
| N2 | "coding-agent 是什么" | 查询定义不是调用 | 无需 skill |
| N3 | "帮我选一个算法" | 决策/分析不需要写代码 | skill-orchestrator 或直接回答 |
| N4 | "代码报错了我怎么解决" | 问解决方案，不是写代码 | skill-orchestrator 或 diagnose |
| N5 | "帮我理解这段代码在做什么" | 理解不需要写代码 | 直接回答 |

---

## BOUNDARY — 边界情况

| # | 触发词 | 边界描述 | 预期行为 |
|---|--------|----------|----------|
| B1 | "写" (单独一字) | 极短 query，无上下文 | 应追问"写什么"而不是触发 |
| B2 | "帮我写代码/帮我写脚本" | 两个触发词叠用 | 正常触发，重复词不造成问题 |
| B3 | "帮我写这段Python代码，然后在服务器上跑起来" | 多步请求（写+部署） | 触发 coding-agent，但需要后续 skill 接力 |
| B4 | "帮我写一个排序，要求时间复杂度 O(n log n)" | 带约束的编码请求 | 触发，约束需要体现在代码中 |
