# 主题色预设（Themes）

**53 套精心调配的主题色板**，分为叙事轴、展示轴和特效轴。只允许从预设中选，不允许自定义 hex 值。

> **资源来源：** 叙事轴 17 套（magazine-web-ppt 遗产）× 特效轴 36 套（html-ppt-skill 遗产，含大量设计风格）。

---

## 叙事轴主题（Narrative — 讲故事、有节奏感）

### 1. 🖋 墨水经典（Narrative · 默认）

**适合**：通用分享、商业发布、科技产品、任何场景都安全的默认选择。
**调性**：纯墨黑 + 暖米白，杂志感最强，Monocle / Apricot / A Book Apart 风。

```css
--ink: #0a0a0b; --ink-rgb: 10, 10, 11;
--paper: #f1efea; --paper-rgb: 241, 239, 234;
--paper-tint: #e8e5de; --ink-tint: #18181a;
```

---

### 2. 🌊 靛蓝瓷（Narrative）

**适合**：科技/研究/数据分享、工程师文化、深度内容、技术发布会。
**调性**：深靛蓝 + 瓷白，冷静、理性、有深度，像学术期刊或蓝印花瓷器。

```css
--ink: #0a1f3d; --ink-rgb: 10, 31, 61;
--paper: #f1f3f5; --paper-rgb: 241, 243, 245;
--paper-tint: #e4e8ec; --ink-tint: #152a4a;
```

---

### 3. 🌿 森林墨（Narrative）

**适合**：自然/可持续/文化/非虚构内容、户外品牌、环保主题。
**调性**：深森林绿 + 象牙，沉稳、有呼吸感，像旧版《国家地理》。

```css
--ink: #1a2e1f; --ink-rgb: 26, 46, 31;
--paper: #f5f1e8; --paper-rgb: 245, 241, 232;
--paper-tint: #ece7da; --ink-tint: #253d2c;
```

---

### 4. 🍂 牛皮纸（Narrative）

**适合**：怀旧/人文/阅读/历史/文学分享、独立杂志、手作品牌。
**调性**：深棕 + 暖米，像牛皮信封或老笔记本，温暖、有年代感。

```css
--ink: #2a1e13; --ink-rgb: 42, 30, 19;
--paper: #eedfc7; --paper-rgb: 238, 223, 199;
--paper-tint: #e0d0b6; --ink-tint: #3a2a1d;
```

---

### 5. 🌙 沙丘（Narrative）

**适合**：艺术/设计/创意/时尚分享、画廊手册、审美优先的私享会。
**调性**：炭灰 + 沙色，克制、高级、中性，像沙漠黄昏或建筑设计图册。

```css
--ink: #1f1a14; --ink-rgb: 31, 26, 20;
--paper: #f0e6d2; --paper-rgb: 240, 230, 210;
--paper-tint: #e3d7bf; --ink-tint: #2d2620;
```

---

### 6. Vintage Editorial（Narrative）

**适合**：witty、confident、editorial、personality-driven 内容。
**调性**：几何图形 + 衬线字，文学感强。
**字体**：Fraunces（700/900）+ Work Sans（400/500）

```css
--bg-cream: #f5f3ee; --text-primary: #1a1a1a;
--text-secondary: #555; --accent-warm: #e8d4c0;
```

---

### 7. Paper & Ink（Narrative）

**适合**：editorial、literary、thoughtful 内容。
**调性**：温暖的米白 + 炭黑 + 猩红点缀，优雅文学感。


## 特效轴主题（Effect-Heavy — 视觉冲击、氛围渲染）

> 来自 html-ppt-skill 遗产，适合需要强烈视觉风格或氛围渲染的场景。

### 18. Cyberpunk Neon（Effect）

**适合**：科技感发布会、AI/赛博朋克主题、Deep Talk。
**调性**：深黑底 + 霓虹青/品红，数字感极强。

```css
--bg: #0a0a0a; --text: #ffffff;
--neon-cyan: #00ffcc; --neon-magenta: #ff00aa;
--neon-yellow: #f0f020; --glow-intensity: 0.8;
```

---

### 19. Aurora（Effect）

**适合**：品牌演示、艺术展示、创新产品发布。
**调性**：极光色渐变 — 青 → 紫 → 粉，流动呼吸感。

```css
--bg: #0a0a1a; --aurora-1: #00d4ff; --aurora-2: #7b2fff; --aurora-3: #ff2d92;
--glow: 0.6; --gradient-angle: 135deg;
```

---

### 20. Glassmorphism（Effect）

**适合**：现代 UI 演示、SaaS 产品介绍、设计系统展示。
**调性**：毛玻璃卡片 + 渐变背景，半透明高级感。

```css
--bg: #1a1a2e; --glass-bg: rgba(255,255,255,0.1);
--glass-border: rgba(255,255,255,0.2);
--accent: #7b2fff; --blur: 12px;
```

---

### 21. Blueprint（Effect）

**适合**：技术架构分享、工程流程、数据系统演示。
**调性**：工程蓝图 — 深蓝底 + 白色/浅蓝线条，等宽字体为主。

```css
--bg: #0a1a3d; --line: #4a9eff; --line-light: #1e5faa;
--text: #e0eaff; --grid: rgba(74,158,255,0.1);
```

---

### 22. Rainbow Gradient（Effect）

**适合**：活泼创意分享、年轻化品牌、儿童教育。
**调性**：彩虹色渐变从左到右，饱和度高。

```css
--bg: #1a1a1a;
--gradient: linear-gradient(90deg, #ff6b6b, #feca57, #48dbfb, #ff9ff3);
--text: #ffffff;
```

---

### 23. Vaporwave（Effect）

**适合**：复古未来主义、设计艺术、科技艺术。
**调性**：80s 复古 + 数字感 — 粉紫 + 青绿 + 网格。

```css
--bg: #1a0a2e; --vapor-pink: #ff71ce;
--vapor-cyan: #01cdfe; --vapor-purple: #b967ff;
--grid: #05ffa1;
```

---

### 24. Y2K Chrome（Effect）

**适合**：复古科技、怀旧主题、互联网历史。
**调性**：Y2K 时代 — 金属质感、渐变、圆润几何。

```css
--bg: #e8e8f0; --chrome: linear-gradient(135deg, #fff, #c0c0c0, #fff);
--accent: #00d4aa; --text: #1a1a2e;
```

---

### 25. Retro TV（Effect）

**适合**：复古内容、电视风格、怀旧演示。
**调性**：老式电视机 — 粗黑边框、扫描线效果、饱和色。


## 切换原则

- **一份 deck 只用一套主题**，不要中途换色
- 选定后，在项目记录里备注，方便后续迭代保持一致
- 叙事轴主题使用 `--ink` / `--paper` / `--ink-rgb` / `--paper-rgb` 变量体系
- 展示轴/特效轴主题使用 `--bg` / `--text` / `--accent` 变量体系

---

## ❌ 不要做的事

- ❌ **不允许混搭**（例如 ink 取墨水经典的，paper 取沙丘的）
- ❌ **不允许用户自定义 hex 值**——需委婉拒绝并展示预设让选
- ❌ **不用系统字体**（Arial、Inter、Roboto）—— 用 Fontshare 或 Google Fonts
